\section{Release v2.2.0 (2026-11-26)}

\subsection{Key New Features}
\begin{enumerate}
    \item \textbf{Group C --- Dedicated Dynamic Response, Broadband Output PSD \& Internal Electro-Optic Probe (\texttt{DYN-01}..\texttt{DYN-04}):}
    Implemented \texttt{tier3\_analysis/scenarios\_dynamic\_probe.py} adding four essential closed-loop characterization scenarios backed by real SystemC-AMS Tier 2 simulations:
    \texttt{DYN-01} (\texttt{dyn\_step\_response}: 10 \& $100^\circ/\text{s}$ steps, 4-State vs 6-State, $K_{\text{tot},1}\in\{0.15,0.25,0.45\}$ sweep, Sagnac vs feedback phase);
    \texttt{DYN-02} (\texttt{dyn\_freq\_response}: 15-pt $20\text{ Hz}$--$10\text{ kHz}$ Bode Magnitude/Phase/Group Delay comparing 4-State $2{,}544\text{ Hz}$ / $65.2\ \mu\text{s}$ and 6-State $1{,}642\text{ Hz}$ / $103.3\ \mu\text{s}$ against half-frame Z-domain theory);
    \texttt{DYN-03} (\texttt{dyn\_output\_psd}: broadband $3\text{ Hz}$--$25\text{ kHz}$ output rate PSD/ASD \& cumulative RMS noise confirming \texttt{EQ-15} ARW $0.000352$ vs $0.000363\,^\circ/\sqrt{\text{h}}$ and $+29.2\text{ dB}$ 6-State LF suppression);
    and \texttt{DYN-04} (\texttt{dyn\_sine\_electro\_optic}: $50^\circ/\text{s}$ @ $250\text{ Hz}$ sinusoidal excitation exposing $\Omega_{\text{in}}/\Omega_{\text{out}}$ [THD $-67.5\text{ dB}$, SFDR $43.6\text{ dB}$], Sagnac phase $\pm 1.180\text{ rad}$, $V_{\text{fb,MIOC}}$ [$391$ $2\pi$ wraps], Photodiode $P_{\text{PD}}/I_{\text{PD}}$ [$r=0.9960$], $V_{\text{TIA}}$, and $60\ \mu\text{s}$ sub-$\tau$ ADC blanking zoom).
    \item \textbf{20-Scenario Default Official Flow, 19-Chart Interactive HTML5 \& Refreshed Curated Example:}
    Expanded \texttt{sim\_runner\_cli.py} to 27 CLI modes, \texttt{viz/plot\_scenarios.py} to 20 300-DPI PNG figures, and \texttt{viz/export\_report.py} to Section 10 Group C Markdown tables + \textbf{19 interactive multi-panel Plotly HTML5 charts}. Re-ran \texttt{./examples/run\_example.sh --sync-example} (\textbf{20 / 20 PASS}) and committed the complete bundle in \texttt{examples/full\_all\_scenarios/}.
    \item \textbf{Governance, 100\% Dual Coverage, 9 Real System Tests \& Rule 16 Sync:}
    Verified 100.0\% C++ ($1{,}546/1{,}546$ lines, $109/109$ functions) and 100.0\% Python line coverage, 41/41 verified formulas, 9/9 real system tests, updated \texttt{skills/}, and synchronized all 3 \texttt{docs/*.\{md,tex,pdf\}}, \texttt{Containerfile}/\texttt{Dockerfile}/\texttt{compose.yaml}, and \texttt{README.md} to \texttt{\DocVersion}.
\end{enumerate}
