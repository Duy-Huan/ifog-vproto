\section{Release v3.0.1 (2026-11-26)}

\subsection{Key New Features}
\begin{enumerate}
    \item \textbf{Code-Audited Interactive HTML5 Mathematical Architecture Explorer (\texttt{viz/architecture\_explorer.py}):}
    Generated standalone \texttt{docs/IFOG\_ARCHITECTURE\_EXPLORER.html} (attached to Release \texttt{v3.0.1}) and automatic per-run \texttt{report/<run\_id>/architecture\_model.html} audited 1-to-1 against live C++/Python source code (\texttt{EQ-01}--\texttt{EQ-44}), with 4 interactive signal-flow highlight modes, non-specialist intuition, live run parameter strip, and formula-to-source audit table.
    \item \textbf{Standardized Professional \texttt{.md} \& \texttt{.html} Reports with Full Theory \& Plain-Language Guides (\texttt{viz/report\_narratives.py}, \texttt{viz/export\_report.py}):}
    Embedded standardized 3-part explanations beneath all \textbf{21 official diagnostic figures} in both Markdown (\texttt{report.md}) and KaTeX/Plotly HTML5 (\texttt{report.html}): (1) theoretical foundation \& exact \texttt{EQ-xx} equations, (2) plain-language reading guide for non-specialists, and (3) dynamically populated quantitative simulation proof, plus sticky quick-navigation bar and embedded interactive architecture diagram inside \texttt{report.html}.

    Re-executed both \texttt{examples/full\_4gate\_baseline/} (\textbf{4 / 4 PASS}) and \texttt{examples/full\_all\_scenarios/} (\textbf{21 / 21 PASS}) with the standardized \texttt{v3.0.1} reporting suite and \texttt{architecture\_model.html}; verified \textbf{100.0\% C++} (\texttt{tier2\_sysc\_ams/} + \texttt{fmi\_wrapper/src/}) and \textbf{100.0\% Python} coverage (including \texttt{viz/architecture\_explorer.py} and \texttt{viz/report\_narratives.py}), 44/44 verified formulas, 10/10 real system tests, and full Rule 16 doc sync.
\end{enumerate}
