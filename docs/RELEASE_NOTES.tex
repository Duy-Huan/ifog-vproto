\subsection{Key New Features (\texttt{IFOG-SIM-SPEC-007} --- High-Fidelity Predictive Physics \& Inverse Calibration)}
\begin{enumerate}
    \item \textbf{Normative Specification \texttt{IFOG-SIM-SPEC-007} v7.0 (\texttt{EQ-45}--\texttt{EQ-53}) \& Schema v6:}
    Authored checksum-locked \texttt{spec/IFOG-SIM-SPEC-007.\{md,tex,pdf,sha256\}} (Quadruple Spec Lock preserving \texttt{SPEC-004/005/006}) and backward-compatible \texttt{configs/schema\_v6.json} + \texttt{configs/baseline\_1km\_spec007.json}; expanded CI formula traceability from 44 to \textbf{53 / 53 verified equations}.
    \item \textbf{Tier 1 Discrete Coil Winding, Elasto-Optic Stress \& 6-Channel \texttt{shupe\_lut.bin} v2 (\texttt{EQ-45}--\texttt{EQ-49}):}
    Added turn-by-turn Quadrupole/Octupole coil winding geometry (\texttt{PHY-01}: $-47.69\%$ octupole Shupe reduction), thermo-mechanical stress-optic drift, dynamic $K_{\text{opt}}(t)/V_{\text{eff}}(t)/\Delta\phi_{\text{pol}}(t)/V_\pi(t)$, and 56-byte \texttt{<7d} binary LUT v2 with transparent v1 fallback.
    \item \textbf{Tier 2 Predictive Parasitics \& Live Tunable FMI 3.0 FMU (\texttt{EQ-50}--\texttt{EQ-52}, \texttt{VR 15..21}):}
    Implemented 2nd-order $\text{LiNbO}_3$ MIOC electro-acoustic step dynamics before $K_{\text{delay}}$, capacitive + resistive PCB crosstalk ($C_{\text{xtalk}}\,dV/dt + G_{\text{xtalk}}V$), coherent Rayleigh/facet back-reflection phase noise, $O(1)$ LUT v2 interpolation, and \textbf{7 live tunable parasitic FMI 3.0 parameters (\texttt{VR 15..21})} in \texttt{build/ifog\_core.fmu} (22 SI variables, 0 XSD errors, bit-exact $0.00\times 10^0\text{ rad/s}$ Gate 6 equivalence).
    \item \textbf{Tier 3 Anti-Double-Counting BI Stitching \& 3-Stage Bounded Inverse Calibration (\texttt{EQ-52}, \texttt{EQ-53}, \texttt{CAL-01}):}
    Added \texttt{DualRegimeStitcher} quadrature BI subtraction and 3-stage bounded \texttt{InverseCalibrator} (\texttt{tier3\_analysis/inverse\_calibration.py}) with Gauss--Newton 95\% CI (\texttt{calibrated\_params.json}), reducing uncalibrated baseline error ($40$--$103\%$) to \textbf{$< 1\%$} across Static AVAR ($0.81\%$), Slow Rate Ramp Deadband ($0.91\%$), Thermal Bias ($0.29\%$), and Scale Factor ($0.04\%$) while recovering all 10 hidden parameters within $\le 2.18\%$ ($< 5\%$ target).
    \item \textbf{Presentation-Grade Tier-by-Tier Mathematical Documentation \& 23/23 Curated Example:}
    Embedded complete tier-by-tier mathematical formulations (\texttt{EQ-01}--\texttt{EQ-53}) in \texttt{IFOG\_VPROTO\_ARCHITECTURE.\{md,tex,pdf\}}, \texttt{IFOG\_ARCHITECTURE\_EXPLORER.html}, and every generated \texttt{report.md} / KaTeX \texttt{report.html}; regenerated \texttt{examples/full\_all\_scenarios/} (\textbf{23 / 23 PASS}, 23 300-DPI PNGs, \texttt{calibrated\_params.json}) at \textbf{100.0\% C++} ($2{,}329/2{,}329$ lines) \& \textbf{100.00\% Python} ($4{,}650/4{,}650$ stmts) coverage.
\end{enumerate}
