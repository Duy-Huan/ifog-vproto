\section{Release v1.1.0 (2026-11-25)}

\subsection{Key New Features}
\begin{enumerate}
    \item \textbf{Automated Markdown (\texttt{.md}) \& Interactive HTML (\texttt{.html}) Simulation Reporting in \texttt{report/}:}
    Upgraded \texttt{viz/export\_report.py} to emit version-stamped Markdown reports (\texttt{report.md}), self-contained interactive Plotly HTML5 reports (\texttt{report.html} featuring Dual-Regime AVAR, Deadband/Bunny Ears, and $1/f$ Flicker PSD plots + KPI tables + 300-DPI gallery), \texttt{metrics\_summary.json}, and auto-maintained \texttt{report/index.\{md,html\}} dashboards.
    \item \textbf{Unified Simulation Runner Script Suite:}
    Added \texttt{tier3\_analysis/sim\_runner\_cli.py}, \texttt{scripts/run\_sim.py}, executable \texttt{scripts/run\_sim.sh}, and console script \texttt{ifog-sim-run} supporting \texttt{single}, \texttt{gate1}, \texttt{gate2}, \texttt{gate3}, \texttt{gate4}, \texttt{full}, and \texttt{sweep} modes with automatic Tier 2 build check and automatic report publication into \texttt{report/}.
    \item \textbf{Synchronized Release \& Architecture Documentation (\texttt{docs/}):}
    Authored \texttt{docs/IFOG\_VPROTO\_ARCHITECTURE.\{md,tex,pdf\}}, \texttt{docs/RELEASE\_NOTES.\{md,tex,pdf\}}, \texttt{docs/CHANGELOG.md}, and reproducible LuaLaTeX builder \texttt{scripts/build\_docs.sh}.
    \item \textbf{Mandatory Version--Document Synchronization Policy (\texttt{AGENT.md} Rule 16):}
    Added Rule 16 and pure-stdlib verifier \texttt{tier3\_analysis/doc\_sync.py} / \texttt{scripts/verify\_doc\_sync.py} enforced in both \texttt{ci.yml} and \texttt{release.yml} (asserting exact alignment between Git release tag \texttt{vX.Y.Z}, \texttt{pyproject.toml}, \texttt{docs/*.\{md,tex,pdf\}}, \texttt{docs/DOCS\_BUILD.sha256}, \texttt{README.md}, and \texttt{AGENT.md}). Added project skill \texttt{skills/ifog-reporting-and-doc-sync/SKILL.md}.
\end{enumerate}
