\section{Release v1.2.0 (2026-11-25)}

\subsection{Key New Features}
\begin{enumerate}
    \item \textbf{Portable Docker \& Podman Container Suite:}
    Added byte-identical \texttt{Containerfile} and \texttt{Dockerfile}, \texttt{.dockerignore}, OCI \texttt{compose.yaml}, and auto-detecting \texttt{scripts/container\_run.sh} (supporting rootless SELinux Podman \texttt{:Z}/\texttt{--userns=keep-id} and Docker). Pre-builds SystemC 2.3.4, SystemC-AMS 2.3.4, \texttt{nlohmann/json} v3.11.3, isolated Python 3.12 venv, and Release \texttt{-O3} \texttt{build/ifog\_sim} ready out of the box, continuously verified via a dedicated CI container job.
    \item \textbf{Distro-Independent Linux Git-Source Setup Toolchain:}
    Added \texttt{scripts/install\_systemc.sh}, upgraded \texttt{scripts/install\_systemc\_ams.sh}, universal bootstrapper \texttt{scripts/setup\_env.sh}, and sourceable \texttt{scripts/env.sh} to build SystemC 2.3.4, SystemC-AMS PoC 2.3.4, \texttt{nlohmann/json}, and Python venv from Git on any Linux distro (Ubuntu/Debian, Fedora/RHEL/Rocky, Arch, rootless HPC) with multi-distro \texttt{CMakeLists.txt} library discovery.
    \item \textbf{Committed Full Real 4-Gate Feasibility Example (\texttt{examples/full\_4gate\_baseline/}):}
    Executed and committed a genuine full-scale 4-Gate baseline run (\texttt{README.md}, \texttt{report.md}, interactive \texttt{report.html}, all Tier 1--3 JSONs, and four 300-DPI PNG figures) plus \texttt{examples/run\_example.sh}: Gate 1 static error $3.10\times 10^{-16}\text{ rad}$ ($1{,}666$ wraps), Gate 2 $98.85\%$ Deadband \& Bunny Ears reduction, Gate 3 linear $-0.062$ vs nonlinear $-0.893$ $1/f$ PSD ($\mathbf{K}$ repeatability $0.000\%$), Gate 4 $4\times 60\text{ s}$ Fast + $12\times 10\text{ h}$ ($3.6\times 10^6$ pts @ $100\text{ Hz}$) Slow AVAR overlap $2.42\% < 5\%$ and all 5 WLS parameters within $\pm 10\%$.
    \item \textbf{Governance \& Skills Sync (Rules 6 \& 16):}
    Added \texttt{skills/ifog-portable-container-env/SKILL.md} and synchronized all \texttt{docs/*.\{md,tex,pdf\}}, \texttt{DOCS\_BUILD.sha256}, \texttt{CHANGELOG.md}, and \texttt{README.md} to \texttt{\DocVersion}.
\end{enumerate}
