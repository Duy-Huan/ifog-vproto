\subsection{Key New Features}
\begin{enumerate}
    \item \textbf{Owner-Authorized Spec Upgrade --- \texttt{IFOG-SIM-SPEC-006} (v6.0) \& 44-Formula Matrix:}
    Authored checksum-locked \texttt{spec/IFOG-SIM-SPEC-006.\{md,tex,pdf,sha256\}} preserving \texttt{SPEC-004} and \texttt{SPEC-005} byte-identical and SHA-256 locked, while expanding the CI formula verification matrix to \textbf{44 / 44 equations (\texttt{EQ-01}--\texttt{EQ-44})}.
    \item \textbf{Standalone Tool-Agnostic FMI 3.0 Co-Simulation FMU (\texttt{build/ifog\_core.fmu}):}
    Wrapped the unmodified Tier 2 Accellera SystemC/SystemC-AMS core (\texttt{IfogTopModule}, compiled \texttt{-fPIC}) via vendorized FMI 3.0 C headers (\texttt{fmi\_wrapper/include/fmi3/}), full 75-symbol C-API bridge (\texttt{fmi\_wrapper/src/fmi3\_bridge.cpp}), 15-variable \texttt{modelDescription.xml.in} (\texttt{fmiVersion="3.0"}, \texttt{canBeInstantiatedOnlyOncePerProcess="true"}), and CMake \texttt{package\_fmu} target bundling \texttt{modelDescription.xml}, \texttt{binaries/x86\_64-linux/ifog\_core.so}, and Tier 1 \texttt{resources/\{phys\_params.json, shupe\_lut.bin, baseline\_cfg.json\}}.
    \item \textbf{FMPy Master Orchestrator \& Gate 6 Verification (\texttt{tier3\_analysis/fmi\_master\_runner.py}, \texttt{--mode fmi\_gate}):}
    Subprocess-isolated FMPy master orchestrator verifying \textbf{0 FMI 3.0 XSD errors} (\texttt{validate\_fmu}), \textbf{bit-exact $0.00\times 10^{0}\text{ rad/s}$ ($<10^{-12}$)} standalone vs FMU equivalence on 4-state \& 6-state modes, \textbf{97.42\%} Deadband reduction (99.59\% Bunny Ears SF reduction) on Slow Rate Ramp across $0^\circ/\text{h}$, and seamless FMU $\to$ Tier 3 Dual-Regime 5-Region IEEE Std 952 AVAR (\textbf{3.83\%} $< 5\%$ overlap, all 5 parameters $\le 8.92\%$).

    Expanded CLI to 28 modes, \texttt{viz/plot\_scenarios.py} to 21 300-DPI PNGs (\texttt{fmi\_fmu\_gate.png}), and \texttt{viz/export\_report.py} to 20 interactive Plotly HTML5 charts; refreshed \texttt{examples/full\_all\_scenarios/} (\textbf{21 / 21 PASS}); verified \textbf{100.0\% C++} (\texttt{tier2\_sysc\_ams/} + \texttt{fmi\_wrapper/src/}) and \textbf{100.0\% Python} line coverage, 10 real system tests, new skill \texttt{skills/ifog-fmi3-cosim-fmu/}, and full Rule 16 doc sync.
\end{enumerate}
